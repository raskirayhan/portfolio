## About me

I am Sheikh Raski Rayhan, a computer science student and full-stack developer based in Bangladesh. I build responsive web products with a strong frontend point of view and a growing focus on APIs, data modeling, authentication, and maintainable delivery workflows.

My best work sits at the intersection of **useful product decisions**, **calm visual systems**, and **engineering that is easy to extend**.

## Current focus

| Focus | What it looks like in practice |
| --- | --- |
| Product engineering | Turning a brief into a responsive, accessible experience with a clear information hierarchy |
| Full-stack systems | Connecting React interfaces to Express APIs, PostgreSQL or MongoDB data, and secure auth flows |
| Developer experience | Writing READMEs, API docs, setup instructions, and checks that make projects easier to run |
| Open source habits | Small, reviewable changes, useful issue reports, and documentation that respects the next contributor |

## Learning now

- Production authentication, validation, and error handling
- Testing strategies for frontend flows and backend contracts
- Performance, accessibility, and deployment observability

## Tech philosophy

> Make the next decision obvious.

I prefer small interfaces, explicit contracts, predictable state, and documentation that tells the truth. A polished product is not only attractive; it is understandable, resilient, and considerate of the person who has to maintain it next.
